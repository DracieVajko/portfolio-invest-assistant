# Security Policy

## Supported Versions

Security fixes are applied to the current default branch.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub private vulnerability reporting if available, or contact the
maintainer through GitHub: https://github.com/DracieVajko

Please include:
- affected file or component
- reproduction steps
- impact assessment
- suggested fix, if available

## Scope

This repository is open source under the MIT License. Please review the code and
dependencies before deploying it in production.

## Response

The maintainer will acknowledge reports as soon as practical and coordinate a
fix and disclosure.
