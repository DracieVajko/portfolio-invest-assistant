## Summary

Earliest preserved snapshot of Portfolio AI Assistant. Single-script portfolio tracker with basic Trading 212 read-only import and Markdown report generation.

- Monolithic `portfolio_ai_assistant.py`
- Trading 212 `auth.py` / `integration.py` / `portfolio.py` (GET-only, no order placement)
- Safe templates: `api.env.example` (empty keys, localhost endpoints) and `portfolio_config.example.json` (demo assets, no real holdings). Local `api.env` and `portfolio_config.json` are gitignored.
- `requirements.txt`, `run_*.bat` helpers
- `.gitignore` covering `api.env`, `.env.*`, `portfolio_config.json`, `PIEs/*.csv` (except `example_*.csv`), `data/`, `logs/`, `reports/`, caches and `fix_*.py`

## Scope and limitations

- Historical reference only. No claim of completeness, accuracy or production readiness.
- No full automated test suite; all outputs require independent validation.
- Read-only research and advisory tool — not financial advice and not an automated trading system. It does not create, modify or cancel broker orders.
