## Summary

Experimental modular beta that rewrites the monolithic `v0.6.0` into a maintainable package structure with market-regime analysis and an isolated research backtest.

- **Modular `investment_engine/`** (`config/settings.py`, `main.py` `run_engine`, `providers/` factory/fallback for Ollama / LM Studio / OpenRouter, `research/` market data / market regime / news engine / peak-valley / technical analysis, `portfolio/` exposure & pie metadata, `reporting/`, `schemas/`, `scoring/`, `pipeline/`, `prompts/`, `memory/`)
- **Multi-timeframe market regime** for EXI2.DE etc.: SMA/EMA/MACD/ADX/Supertrend/RSI/CCI/ATR/OBV/VWAP, Fibonacci levels, peak/valley detection, daily/weekly/monthly/15m/1h via `yfinance`
- **Pie-level exposure** (`PIEs/config/*.json` tracked, `PIEs/example_*.csv` tracked; real `PIEs/*.csv` gitignored)
- **Isolated experimental backtest** (`experimental/backtest/`): deterministic indicators, `tech_pie_pullback_v1` strategy, next-open execution, dated FX configs (`experimental/backtest/config/*.json`), `data_hash`/`fx_hash`/`config_hash`. No Trading 212, LLM or network calls in the core; 7 tests including `test_no_lookahead.py`.

## Stability

- **Beta / WIP — may contain bugs, incomplete features, incorrect calculations, data-provider edge cases, configuration incompatibilities and breaking changes.**
- Configuration keys and report schemas may change without migration.
- Requires independent validation before any investment decision. **Do not rely on it for investment decisions or live trading.**

## Experimental backtest — research only

- Research and advisory use only; **does not imply future profitability**.
- Must be validated for look-ahead bias, survivorship bias, costs and slippage. Passing a backtest is not a guarantee.
- Isolated from Trading 212 and LLMs; consumes only local OHLCV data.

## Safe setup and privacy

- Never commit secrets: use `api.env.example` → `api.env` and `portfolio_config.example.json` → `portfolio_config.json` (both `*.example` are safe templates; the locals are gitignored).
- Private / runtime files are gitignored: `api.env`, `portfolio_config.json`, `PIEs/*.csv` (except `example_*`), `data/`, `logs/`, `reports/`, `investment_engine/memory/memory.json`, caches (`__pycache__/`, `*.db`), `fix_*.py`
- Read-only: Trading 212 integration is GET-only; the tool does not create, modify or cancel broker orders and is **not financial advice**.
