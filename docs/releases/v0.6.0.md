# v0.6.0 — Current stable monolithic release

> **Current stable release.**
> This monolithic version is currently used for regular local portfolio monitoring and reporting.
>
> It remains a pre-1.0 project without comprehensive automated test coverage. Independently validate all data, calculations, and outputs before making financial decisions.

**Tag:** `v0.6.0`
**Commit:** `feat: add stable monolithic portfolio workflow`
**Status:** Current stable monolithic release. Maintenance-oriented snapshot, not a full rewrite.

## Overview

Sanitized, maintenance-oriented continuation of the monolithic line. Based on the historical `Zalohy/portfolio_ai_assistant_V4_5` backup, sanitized for public staging and local Git. This is the release actively used for regular local monitoring.

## Improvements over v0.5.0

- Deterministic `portfolio_ai_assistant.py` with Trading 212 read-only import (`GET` only), multi-source news (`yfinance`, `DDGS`), and Markdown + JSON reporting (`reports/portfolio_analysis.md` / `.json` + `reports/archive/`)
- `trading212/` package (`auth.py`, `portfolio.py`, `integration.py`) — the monolith still contains inline Trading 212 logic as well (dual implementation documented as tech debt)
- Sanitized `api.env.example` and `portfolio_config.example.json` with localhost placeholders (`http://127.0.0.1:11434`, `http://127.0.0.1:1234/v1`, `http://127.0.0.1:7000`) and demo assets (`AAPL`, `MSFT`, `BTC-USD`). Local `portfolio_config.json` (gitignored) is identical to the example for out-of-the-box `python portfolio_ai_assistant.py --no-ai`.
- `PIEs/example_*.csv` + `PIEs/README.md`; real `PIEs/*.csv` and `investment_engine/memory/memory.json` remain gitignored
- `.gitignore` covering secrets, runtime output (`data/`, `logs/`, `reports/`), caches (`__pycache__/`, `.pytest_cache/`, `*.db`) and temporary patches (`fix_*.py`)
- `CHANGELOG.md` and this release note; `CLEANUP_REPORT.md` documents the sanitization

## Known limitations

- **No full automated test suite.** This snapshot ships without comprehensive tests; live providers (yfinance, DDGS, Trading 212) may be unavailable or rate-limited.
- **Outputs must be independently validated.** Prices, signals, probabilities and LLM tidy-ups must be cross-checked before any decision. Do not rely on it as sole basis for investment decisions.
- Read-only advisory tool: it does not create, modify or cancel broker orders and is not financial advice.

## Safe setup

```bash
pip install -r requirements.txt
copy api.env.example api.env
copy portfolio_config.example.json portfolio_config.json
python portfolio_ai_assistant.py --no-ai
```

## Security and privacy

- Never commit secrets: use `api.env.example` → `api.env` and `portfolio_config.example.json` → `portfolio_config.json` (both `*.example` are safe templates; the locals are gitignored).
- Private / runtime files are gitignored: `api.env`, `portfolio_config.json`, `PIEs/*.csv` (except `example_*`), `data/`, `logs/`, `reports/`, `investment_engine/memory/memory.json`, caches (`__pycache__/`, `*.db`), `fix_*.py`
- Read-only: Trading 212 integration is GET-only; the tool does not create, modify or cancel broker orders and is **not financial advice**.

## Status

This release is recommended for users who want the current monolithic workflow. The V5 beta (`v1.0.0-beta.1` on `main`) is an experimental modular rewrite and not production-ready.
