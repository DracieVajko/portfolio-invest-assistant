## What was sanitized

- **Not carried over:** `api.env`, `.env`, `portfolio_config.json` (real), `data/`, `logs/`, `reports/`, `PIEs/*.csv`, `__pycache__/`, `.venv/`, `*.db`, `*.log`, `fix_call_stage.py`, `fix_settings.py`, `investment_engine/memory/memory.json`, `*Conflict*`, `.git/`.
- **Replaced with safe templates:** `api.env.example` (empty credentials, localhost placeholders), `portfolio_config.example.json` + gitignored `portfolio_config.json` (3 demo assets, no financial values, sanitized URLs, conservative defaults).
- **PIEs:** real exports removed; `PIEs/README.md` + four `example_*.csv` (header + 2 fictitious rows).
- **No personal paths, private IPs, or financial values** were retained (verified by scan).

## What was fixed (minimal, no refactor)

1. **`load_dotenv`** — added `try: from dotenv import load_dotenv` with `_HAS_DOTENV` fallback; `load_environment_variables()` now tolerates missing `api.env` and missing dependency.
2. **Batch paths** — `run_t212_analysis.bat` and `run_t212_export.bat` now call `python trading212\integration.py` with `%~dp0`-relative paths.
3. **`requirements.txt`** — removed exact duplicate `ddgs>=0.2.0`.
4. **Temporary patches** — `fix_call_stage.py` / `fix_settings.py` not transferred; their edits already present in `portfolio_ai_assistant.py`.
5. **Duplicate definitions** — removed earlier identical `migrate_legacy_config` and `validate_config`; kept later effective versions. Remaining duplicates (`check_ollama_available` ×2, `get_working_model` ×2) are documented as tech debt.

## What was intentionally left as technical debt

- **Dual T212 implementation** — `portfolio_ai_assistant.py` inline helpers and `trading212/` package both implement read-only Trading 212. No monolith→package migration was performed.
- **Duplicate helpers** — `check_ollama_available` and `get_working_model` each appear twice; the later definition wins at runtime. Removing the earlier one would change no behaviour but was left for minimal-risk maintenance.
- **No test suite** — validate outputs independently.

## Static validation (no network, no execution)

## Safe setup (reminder)
